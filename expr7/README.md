# Experiment 7: React Practice Questions

This experiment contains 10 React practice applications, each demonstrating different React concepts including state management, hooks, and component interaction.

## Setup

```bash
npm install
npm run dev
```

## Practice Questions

Each practice question is in a separate folder under `src/pq[1-10]/`:

1. **Calculator App** - Basic arithmetic operations with memory storage
2. **Tip Calculator** - Calculate tips and split bills
3. **Stopwatch** - Timer with start, pause, reset, and lap functionality
4. **Weather App** - Display weather information (mock data)
5. **Expense Tracker** - Track income and expenses with categories
6. **Grocery List** - Add, edit, delete, and mark items as bought
7. **Notes App** - Create, edit, delete notes with tags
8. **Unit Converter** - Convert between length, weight, and volume units
9. **Password Generator** - Generate secure passwords with custom options
10. **Quiz App** - Multiple-choice quiz with score tracking

## Usage

Use the dropdown menu in the app to switch between different practice questions.
